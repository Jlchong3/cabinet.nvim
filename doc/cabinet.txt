------------------------------------------------------------------------------
								       *cabinet*

Instead of maintaining a single global list of marked buffers, with
cabinet.nvim you organize your workflow into isolated "drawers." It is
perfect for grouping related files by feature or task, allowing
you to instantly switch contexts and jump between buffers.

------------------------------------------------------------------------------
                                                               *cabinet.setup()*
                            `cabinet.setup`({opts})
Initializes the cabinet module: registers autocommands and returns the public API.
Parameters ~
{opts} `(table?)` Reserved for future configuration options
Return ~
`(table)` M The public cabinet API

------------------------------------------------------------------------------
                                                  *cabinet.get_current_drawer()*
                         `cabinet.get_current_drawer`()
Returns the 1-based index of the currently active drawer, or -1 when no drawer is open.
Return ~
`(integer)` drawer_pos

------------------------------------------------------------------------------
                                                          *cabinet.add_drawer()*
                         `cabinet.add_drawer`({drawer})
Creates a new drawer with the given name.
If `drawer` is nil the user is prompted interactively.
If `drawer` is an empty string, `"default"` is used.
Returns nil if the drawer already exists or the input was cancelled.
Parameters ~
{drawer} `(string?)` Name for the new drawer (optional; prompts if nil)
Return ~
`(string|nil)` drawer The name of the created drawer, or nil on failure

------------------------------------------------------------------------------
                                                       *cabinet.remove_drawer()*
                     `cabinet.remove_drawer`({drawer_pos})
Removes the drawer at position `drawer_pos` from the cabinet.
Adjusts `current_drawer` so it remains valid after the removal.
Does nothing when `drawer_pos` is out of range.
Parameters ~
{drawer_pos} `(integer)` 1-based index of the drawer to remove

------------------------------------------------------------------------------
                                               *cabinet.remove_drawer_by_name()*
                   `cabinet.remove_drawer_by_name`({drawer})
Removes the drawer with the given name.
Adjusts `current_drawer` so it remains valid after the removal.
Does nothing when the drawer does not exist.
Parameters ~
{drawer} `(string)` Name of the drawer to remove

------------------------------------------------------------------------------
                                                 *cabinet.open_drawer_by_name()*
                    `cabinet.open_drawer_by_name`({drawer})
Sets the active drawer to the one with the given name.
Does nothing when the drawer does not exist.
Parameters ~
{drawer} `(string)` Name of the drawer to open

------------------------------------------------------------------------------
                                                         *cabinet.open_drawer()*
                      `cabinet.open_drawer`({drawer_pos})
Sets the active drawer to the one at position `drawer_pos`.
Does nothing when `drawer_pos` is out of range.
Parameters ~
{drawer_pos} `(integer)` 1-based index of the drawer to open

Renames the drawer at position `drawer_pos`.
Does nothing when `drawer_pos` is out of range or `new_name` is already taken.
Parameters ~
{drawer_pos} `(integer)` 1-based index of the drawer to rename
{new_name} `(string)` Desired new name

------------------------------------------------------------------------------
                                                            *cabinet.add_file()*
                        `cabinet.add_file`({drawer_pos})
Appends the current buffer to a drawer and records its cursor position.
If `drawer_pos` is nil, uses the active drawer; creates one named `"default"`
when no drawers exist yet.
Returns the 1-based index of the newly added file within its drawer, or -1 on failure.
Parameters ~
{drawer_pos} `(integer?)` 1-based index of the target drawer (defaults to `current_drawer`)
Return ~
`(integer)` file_index Index of the added file within the drawer, or -1 on failure

------------------------------------------------------------------------------
                                                         *cabinet.remove_file()*
               `cabinet.remove_file`({file_index}, {drawer_pos})
Removes the file at `file_index` from the drawer at `drawer_pos`.
Does nothing when either index is out of range.
Parameters ~
{file_index} `(integer)` 1-based index of the file within the drawer
{drawer_pos} `(integer)` 1-based index of the drawer in `drawer_order`

------------------------------------------------------------------------------
                                                           *cabinet.open_file()*
                `cabinet.open_file`({file_index}, {drawer_pos})
Opens the file at `file_index` inside the drawer at `drawer_pos`.
If `drawer_pos` is nil, uses the active drawer.
Restores the previously saved cursor position after opening.
Does nothing when the file is already the current buffer or indices are out of range.
Parameters ~
{file_index} `(integer)` 1-based index of the file within the drawer
{drawer_pos} `(integer?)` 1-based index of the drawer (defaults to `current_drawer`)

------------------------------------------------------------------------------
                                                                *storage.save()*
                   `storage.save`({tbl}, {path}, {is_empty})
Persists the cabinet table to disk for the current working directory.
The file is named after a SHA-256 hash of the cwd path, so each project
gets its own isolated state file.
If `is_empty` returns true and no file exists yet, the write is skipped
to avoid creating empty data files.
Parameters ~
{tbl} `(table)` The cabinet table to persist
{path} `(string)` Absolute path to the directory where cabinet data files are stored
{is_empty} `(fun(tbl: table): boolean)` Predicate that returns true when the cabinet holds no meaningful data

------------------------------------------------------------------------------
                                                                *storage.load()*
                             `storage.load`({path})
Loads the cabinet table previously saved for the current working directory.
Returns nil when no data file exists yet (first run in this project).
Parameters ~
{path} `(string)` Absolute path to the directory where cabinet data files are stored
Return ~
`(table|nil)` cabinet The deserialized cabinet table, or nil if no data file is found

------------------------------------------------------------------------------
                                                                     *ui.open()*
                               `ui.open`({opts})
Opens the drawer floating window.
If the window is already open, focuses it without reinitializing.
Sets up all buffer-local keymaps and autocommands on first open:

Keymaps (normal mode):
- `<CR>` — in drawer list: open selected drawer's file list;
           in file list: close window and open the selected file.
- `-`    — in file list: return to the drawer list.
- `q`    — close the window.

Autocommands (buffer-local):
- `InsertLeave` — persist edits and refresh the buffer.
- `VimResized`  — recompute and apply the window dimensions.
Parameters ~
{opts} `(vim.api.keyset.win_config?)` Optional overrides for the window configuration

------------------------------------------------------------------------------
                                                                    *ui.close()*
                                  `ui.close`()
Closes the floating drawer window and persists any edits made in the buffer.
Flushes drawer list edits when in the top-level view,
or file list edits when in the file list view.
